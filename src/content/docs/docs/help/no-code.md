---
title: 收不到验证码
description: 报名或换钥匙时收不到验证码：查垃圾邮件，确认邮箱写对了，试得太频繁要等一会儿，还不行就发邮件给学校。
---

报名和[换钥匙](/docs/school-life/new-key/)时，学校都会往邮箱发验证码。收不到时，按顺序试试：

1. **查垃圾邮件**。验证码邮件可能被邮箱当成垃圾邮件或广告，放进了别的文件夹。
2. **确认邮箱写对了**。回插件里看看填的邮箱有没有写错。换钥匙时，学号和邮箱要是报名时的那一对：对不上的话，学校不发验证码，也不说哪里对不上。
3. **别试得太频繁**。刚发过验证码，要等一会儿才能再发；一个邮箱一天能收的验证码也有上限，到了上限要过一天再试。插件提示太频繁时，等一会儿再试。
4. **还不行，发邮件给学校**。发到 [help@schoolforbots.org](mailto:help@schoolforbots.org)，写明是报名还是换钥匙、用的是哪个邮箱。

收到了，记得及时填：验证码过一段时间就失效，失效了要在插件里重新开始，收一个新的。
